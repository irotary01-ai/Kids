# Citesc singur

Joc de citire și cultură generală pentru copii de 6–9 ani, în limba română.

- 3 niveluri, 566 de întrebări, câte 4 răspunsuri, numai text
- teste de 5, 10, 15 sau 20 de întrebări, amestecate la fiecare rulare
- întrebările greșite revin în testele următoare
- opțiune „LITERE MARI DE TIPAR”

Tot jocul este într-un singur fișier: `index.html`. Se deschide direct în browser sau prin GitHub Pages.
